# ⚔ Fantasy Inventory Manager

A fantasy-themed inventory management application built with vanilla HTML, CSS, and JavaScript.

Designed as a tool for RPG players, worldbuilders, character creators, and inventory organization, this project combines an immersive fantasy aesthetic with a flexible, interactive inventory system.

## 🌐 Live Demo

**Try it here:**
https://phaizona.github.io/inventorymanager/

## Features

### 🎒 Item Creation

* Upload custom item images
* Assign item names
* Set stack quantities
* Drag & drop image upload support

### 🗺 Infinite Inventory Canvas

* Freely place items anywhere on the canvas
* Drag items to reposition them
* Zoom in and out
* Pan across the world space
* Organize inventories visually instead of using traditional grids

### ⚔ Item Management

* Stack quantities
* Split stacks ("Take One")
* Clone item stacks
* Rename items
* Remove items
* Quick quantity controls

### 💾 Data Persistence

* Automatic local saving using LocalStorage
* Inventory remains available after refreshing or reopening the page
* No account or server required

### 📦 Backup & Sharing

* Export inventory data as JSON
* Import previously saved inventories
* Easy backup and restoration

## Built With

* HTML5
* CSS3
* Vanilla JavaScript
* LocalStorage API
* FileReader API
